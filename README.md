# socket_programming_in_c-lab
The idea behind this repository is simple. First I build a project and test it to ensure it works, then, I try to hack my own code to find security vulnerabilities. Once I find those bugs, I start rebuilding the project with all the bugs fixed and write an article explaining what the bugs were, why they happened, and how to prevent them, because of this, you will see two versions of the same project, the secure version is labeled V2 at the end.

While most GitHub repositories only provide the latest updated code, I include both the original and updated versions. This repository is not meant to just give you a tool or code to run it is designed to explain my methodology for understanding, building, and fixing bugs.
